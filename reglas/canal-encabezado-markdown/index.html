Encabezado de Markdown

canal-encabezado-markdown

Una línea que empieza por almohadillas, como «## Título»: un título del chat sin convertir. Solo avisa.

Solo aviso: no suma.

Qué hacer

Quita el formato Markdown: borra las almohadillas y deja el título como una línea normal, o dale formato de título con tu editor.

Explicación

Una línea que empieza por una a seis almohadillas y un espacio (## Así) es un encabezado de Markdown sin convertir. Este rasgo indica que el texto se copió de un asistente sin limpiar; no dice nada de quién lo escribió. Medido en inglés (Freeburg, 2026): sin pedirles otra cosa, GPT-4o, Claude Sonnet 4 y GPT-4.1 dejan de 5,4 a 6,3 marcas de Markdown por cada 1.000 palabras, y GPT-5.4 ninguna. Cuando aparece dice mucho; cuando no aparece, no dice nada. Wikipedia también lo recoge: títulos de sección con almohadillas.

Excepciones

  • Documentación técnica, notas o ficheros escritos en Markdown a propósito.
  • Las almohadillas de un bloque de código (los comentarios de un script) no cuentan: el motor no mira el código.
  • Una etiqueta pegada a la palabra (#radiografia) no es un encabezado y no cuenta.
  • Texto cortado a mano (encargo 6.1: párrafos según CommonMark): un encabezado es siempre su propio bloque, así que la excepción web (párrafo nuevo tras un punto y una mayúscula) no cambia lo que mira esta regla. Si el corte deja «# » al principio de una línea, eso sí cuenta como encabezado.
